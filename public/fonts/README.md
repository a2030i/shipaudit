# خط الهوية Janna LT

ضع هنا ملفات خط **Janna LT** الرسمية (من رخصة هوية لمحة):

- `JannaLT-Regular.woff2` (أو `JannaLT-Regular.ttf`)
- `JannaLT-Bold.woff2` (أو `JannaLT-Bold.ttf`)

بمجرد وضع الملفات يعمل الخط تلقائياً في كل النظام (معرَّف في `src/index.css`
عبر `@font-face` وأول عائلة في `--font-sans`). حتى وصولها يسقط المتصفح
تلقائياً لخط PingARLT — لا ينكسر شيء.

> لا تُحمَّل الملفات من مواقع خطوط مقرصنة — المصدر رخصة الشركة فقط.
